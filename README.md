# Aliance Site (Astro)

Site institucional da Aliance Vistorias migrado para Astro com componentes React.

## Scripts

- `pnpm dev`: inicia ambiente local
- `pnpm build`: gera build de produção
- `pnpm preview`: serve a build localmente
- `pnpm lint`: executa ESLint

## Stack

- Astro
- React
- Tailwind CSS
- TypeScript
